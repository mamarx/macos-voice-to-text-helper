  <name>Task 2: Implement menu bar icon state management</name>
  <files>

  <action>
Create `aihelper/MenuBarManager.swift` with an `ObservableObject` class that manages recording state and the corresponding menu bar icon:

1. `MenuBarManager` class (ObservableObject):
   - `@Published var isRecording: Bool = false`
   - Computed property `statusIconName: String` that returns:
     - `"mic"` when idle (isRecording == false)
     - `"mic.fill"` when recording (isRecording == true) — the filled variant provides clear visual distinction
   - Method `toggleRecording()` that flips `isRecording` (actual audio logic comes in Plan 02)

2. Update `aihelperApp.swift`:
   - Add `@StateObject private var menuBarManager = MenuBarManager()`
   - Wire the `MenuBarExtra` icon to `menuBarManager.statusIconName` using `Image(systemName:)`
   - If using SwiftUI `MenuBarExtra` with `isInserted` binding, use the string-label initializer: `MenuBarExtra(menuBarManager.statusIconName, systemImage: menuBarManager.statusIconName)`
   - Add a menu item "Toggle Recording" that calls `menuBarManager.toggleRecording()` — this is a temporary test mechanism until global hotkey is wired in Plan 02
   - Keep the "Quit" menu item

**Important:** SwiftUI `MenuBarExtra`'s `systemImage` parameter is evaluated once. If dynamic icon updates don't work with `MenuBarExtra`, refactor to use AppKit's `NSStatusItem` approach instead:
   - In `MenuBarManager`, create and own an `NSStatusItem` via `NSStatusBar.system.statusItem(withLength: .squareLength)`
   - Set `button.image = NSImage(systemSymbolName: iconName, accessibilityDescription: "aihelper")`
   - Update the icon in `isRecording`'s `didSet`
   - Build an `NSMenu` programmatically with Toggle Recording and Quit items

Choose whichever approach (pure SwiftUI MenuBarExtra or AppKit NSStatusItem) produces a working dynamic icon. Document the choice in code comments.
