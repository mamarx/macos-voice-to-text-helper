  <action>
Create CodewordDetector as a class (not actor -- needs synchronous buffer append from audio tap callback) that performs periodic whisper transcription on a rolling audio buffer to detect the configured stop codeword.

**Architecture:**
- Maintains a rolling buffer of Float audio samples (last ~3 seconds of audio at 16kHz = ~48,000 samples)
- Every ~2 seconds, runs a whisper transcription pass on the buffer contents
- Checks if the transcription contains the codeword (case-insensitive)
- If detected, calls `onCodewordDetected` callback

**Implementation details:**

```swift
final class CodewordDetector {
    /// Called when the codeword is detected in audio. Called on background thread.
    var onCodewordDetected: (() -> Void)?

    /// Rolling buffer of 16kHz mono Float samples
    private var audioBuffer: [Float] = []

    /// Maximum buffer size: ~4 seconds at 16kHz (enough for detection with margin)
    private let maxBufferSamples = 16000 * 4

    /// Whisper context for codeword detection (separate from main transcription context)
    private var whisperContext: OpaquePointer?

    /// Timer for periodic transcription checks
    private var detectionTimer: DispatchSourceTimer?

    /// Whether detection is active
    private(set) var isActive: Bool = false

    /// Serial queue for buffer access and transcription
    private let queue = DispatchQueue(label: "com.aihelper.codeword", qos: .userInteractive)
}
```

**Key methods:**

1. `start(modelPath: String)` -- Creates a separate whisper context (lightweight, reuses same model file) and starts a DispatchSourceTimer that fires every 2 seconds on the serial queue. Each timer tick calls `checkForCodeword()`.

2. `stop()` -- Cancels timer, clears buffer, frees whisper context. Must be safe to call multiple times.

3. `appendAudio(_ samples: [Float])` -- Appends samples to rolling buffer on the serial queue. If buffer exceeds maxBufferSamples, trims from the front (keeps most recent audio).

4. `checkForCodeword()` -- Runs on the serial queue:
   - If buffer has < 8000 samples (< 0.5s), skip (not enough audio)
   - Run `whisper_full()` on buffer contents with fast settings:
     - `params.n_threads = 4` (fewer threads since running alongside main capture)
     - `params.no_context = true`
     - `params.single_segment = true` (we only need one segment for short buffer)
     - `params.language = nil` (auto-detect, same as main)
   - Collect transcribed text from all segments
   - Check if lowercased text contains the lowercased codeword from `SettingsManager.shared.codeword`
   - If found, call `onCodewordDetected?()` on the callback and call `stop()` to prevent multiple triggers

**Important:** Use `whisper_init_from_file_with_params` with `flash_attn = true` for Metal acceleration, same as TranscriptionManager. The whisper context is lightweight (~20MB overhead) -- the model weights are memory-mapped and shared by the OS.

Import the `whisper` module at top of file.

The codeword check should be tolerant: trim whitespace, check `contains` not exact match, and be case-insensitive. This handles whisper outputting "Over." or " over" etc.

In the `startCapture()` method, inside the `inputNode.installTap` closure, after writing the converted buffer to the audio file, also forward the Float samples to the codeword detector:

```swift
// Forward audio to codeword detector for live analysis
if let detector = self.codewordDetector, detector.isActive {
    // Convert the buffer to [Float] for the detector
    // The convertedBuffer is in Int16 format, convert to Float
    if let channelData = convertedBuffer.int16ChannelData {
        let frameCount = Int(convertedBuffer.frameLength)
        var floatSamples = [Float](repeating: 0, count: frameCount)
        for i in 0..<frameCount {
            floatSamples[i] = Float(channelData.pointee[i]) / 32768.0
        }
        detector.appendAudio(floatSamples)
    }
}
```

Note: The audio tap buffer is in the target format (16kHz mono Int16). We need to convert Int16 samples to Float for the codeword detector since whisper expects Float input. Access `convertedBuffer.int16ChannelData` since the format is pcmFormatInt16.

In `processRecording(url:)`, after getting the transcribed text, strip the codeword from the end of the text:
```swift
var trimmed = text.trimmingCharacters(in: .whitespacesAndNewlines)
// Strip codeword from end of transcription
let codeword = SettingsManager.shared.codeword.lowercased()
if trimmed.lowercased().hasSuffix(codeword) {
    trimmed = String(trimmed.dropLast(codeword.count))
        .trimmingCharacters(in: .whitespacesAndNewlines)
}
// Also handle "over." with trailing punctuation
let codewordWithPunctuation = codeword + "."
if trimmed.lowercased().hasSuffix(codewordWithPunctuation) {
    trimmed = String(trimmed.dropLast(codewordWithPunctuation.count))
        .trimmingCharacters(in: .whitespacesAndNewlines)
}
```

This ensures the codeword itself does not appear in the inserted text.
