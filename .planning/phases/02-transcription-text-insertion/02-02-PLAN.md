  <name>Task 1: Create TextInsertionManager with typing simulation and clipboard fallback</name>
  <files>aihelper/TextInsertionManager.swift</files>
  <action>
1. **Create `aihelper/TextInsertionManager.swift`**:

   - `final class TextInsertionManager` with a single public method: `func insertText(_ text: String)`.
   - The method tries CGEvent-based typing simulation first, falls back to clipboard paste if it fails.

   **Primary method -- CGEvent typing simulation (INS-01):**
   - For each Unicode scalar in the text string:
     a. Create a `CGEvent` with type `.keyDown` using `CGEvent(keyboardEventSource: nil, virtualKey: 0, keyDown: true)`.
     b. Set the Unicode character via `event.keyboardSetUnicodeString(stringLength: 1, unicodeString: &char)` where char is the UTF-16 code unit.
     c. Post the keyDown event to `.cghidEventTap` using `event.post(tap: .cghidEventTap)`.
     d. Create and post a matching `.keyUp` event.
     e. Add a tiny delay between characters (usleep(1000) = 1ms) to avoid overwhelming the receiving application.
   - Wrap the entire typing loop in a try/catch or guard. If ANY CGEvent creation returns nil (which happens when the app lacks Accessibility permission for event posting, or the target app rejects synthetic events), immediately fall back to clipboard paste.

   **Fallback method -- Clipboard paste (INS-02):**
   - Save the current clipboard content using `NSPasteboard.general.string(forType: .string)`.
   - Set the transcribed text on the clipboard: `NSPasteboard.general.clearContents()` then `NSPasteboard.general.setString(text, forType: .string)`.
   - Simulate Cmd+V keystroke using CGEvent:
     a. Create keyDown event for 'v' key (virtual key code 9).
     b. Set `.maskCommand` flag on the event.
     c. Post keyDown then keyUp.
   - After a short delay (usleep(100_000) = 100ms to let the paste complete), restore the original clipboard content if it was non-nil.

   - IMPORTANT: Both typing simulation and Cmd+V paste require Accessibility permission (same permission already requested by HotkeyManager in Phase 1 for CGEvent tap). No new permission needed.
   - IMPORTANT: Use `CGEvent.post(tap: .cghidEventTap)` not `.cgSessionEventTap` -- cghidEventTap works for simulating input to other applications.

2. **Verify build**: `swift build` succeeds.

  </verify>

1. **Update `aihelper/MenuBarManager.swift`** to orchestrate the full pipeline:

   - Add new published state: `@Published var isTranscribing: Bool = false`. This gives the UI a third state (idle / recording / transcribing).
   - Update `statusIconName` computed property to return three states:
     - idle: `"mic"` (existing)
     - recording: `"mic.fill"` (existing)
     - transcribing: `"text.bubble"` (SF Symbol indicating text processing) -- use `isTranscribing ? "text.bubble" : (isRecording ? "mic.fill" : "mic")`
   - Add private properties:
     - `private var transcriptionManager: TranscriptionManager?`
     - `private let textInsertionManager = TextInsertionManager()`
   - Add `func initializeTranscription() async`:
     a. Check `ModelManager.shared.isModelDownloaded`. If not, download with `await ModelManager.shared.downloadModel(progress: { p in print("Downloading model: \(Int(p * 100))%") })`.
     b. Create transcription context: `transcriptionManager = try await TranscriptionManager.createContext(path: ModelManager.shared.modelPath)`.
     c. Print success/failure message.
   - Modify `stopRecording()` to become `private func stopRecording()` that:
     a. Gets the recording URL from `audioCaptureManager.stopCapture()`.
     b. Sets `isRecording = false`.
     c. If URL exists AND transcriptionManager is not nil:
        - Set `isTranscribing = true` on main thread.
        - Dispatch to a Task: `Task { await self.processRecording(url: url) }`.
     d. If transcriptionManager is nil, print warning that model not loaded yet.
   - Add `private func processRecording(url: URL) async`:
     a. Call `let text = try await transcriptionManager!.transcribe(audioURL: url)`.
     b. On main thread: set `isTranscribing = false`.
     c. If text is not empty (after trimming whitespace), call `textInsertionManager.insertText(text)` on main thread.
     d. Clean up: delete the temporary WAV file using `try? FileManager.default.removeItem(at: url)`.
     e. Wrap in do/catch -- on error, set `isTranscribing = false` and print the error.

   - IMPORTANT: The `@Published` property changes MUST happen on the main thread (use `DispatchQueue.main.async` or `@MainActor`). The transcription runs in a background Task. The text insertion must happen on the main thread since CGEvent posting is main-thread-safe.
   - IMPORTANT: Do NOT change the existing startRecording() logic. Only modify stopRecording() and add the new pipeline methods.

   - Alternative approach if `.task` doesn't work on MenuBarExtra: in `aihelperApp.init()`, dispatch an async task: `Task { await menuBarManager.initializeTranscription() }` -- but be careful with @StateObject timing. The cleanest approach may be to have MenuBarManager.init() dispatch the async model initialization itself using `Task { await self.initializeTranscription() }` at the end of its init().
