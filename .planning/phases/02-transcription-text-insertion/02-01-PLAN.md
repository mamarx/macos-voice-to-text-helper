<task type="auto">
  <name>Task 1: Add whisper.spm dependency and create TranscriptionManager</name>
  <files>Package.swift, aihelper/TranscriptionManager.swift</files>
  <action>
1. **Update Package.swift** to add whisper.spm as a dependency:
   - Add `.package(url: "https://github.com/ggerganov/whisper.spm", branch: "master")` to dependencies array (MUST use branch "master", not a version tag -- the whisper.spm README explicitly warns that version-based resolution causes unsafe build flag errors).
   - Add `.product(name: "whisper", package: "whisper.spm")` to the aihelper executable target dependencies.

2. **Create `aihelper/TranscriptionManager.swift`** -- an actor-based wrapper around the whisper C API:

   - Import `Foundation` and `whisper` (the module exposed by whisper.spm).
   - Do NOT import UIKit (this is macOS, not iOS). Use `import AppKit` only if needed (likely not needed here).
   - Create `actor TranscriptionManager` following the same actor pattern as the official whisper.swiftui example (actor prevents concurrent access to the whisper context pointer).
   - Private stored property `context: OpaquePointer` holding the whisper context.
   - Private init accepting the context pointer. Public static factory `createContext(path: String) throws -> TranscriptionManager` that calls `whisper_init_from_file_with_params(path, params)` where params has `flash_attn = true` for Metal acceleration on Apple Silicon.
   - deinit calls `whisper_free(context)`.
   - `func transcribe(audioURL: URL) async throws -> String` method:
     a. Read the WAV file at audioURL, skip the 44-byte WAV header, convert the remaining Int16 PCM samples to `[Float]` normalized to [-1.0, 1.0] range (divide by 32768.0). The WAV files from AudioCaptureManager are 16kHz/mono/16-bit PCM.
     b. Configure `whisper_full_default_params(WHISPER_SAMPLING_GREEDY)` with:
        - `params.print_realtime = false`
        - `params.print_progress = false`
        - `params.print_timestamps = false`
        - `params.print_special = false`
        - `params.translate = false`
        - `params.language = nil`  -- THIS IS CRITICAL: nil means auto-detect language (satisfies TRX-03 for German+English without manual selection)
        - `params.n_threads = Int32(max(1, min(8, ProcessInfo.processInfo.processorCount - 2)))`
        - `params.no_context = true`
        - `params.single_segment = false`
     c. Call `whisper_full(context, params, samples.baseAddress, Int32(samples.count))`. Check return value -- 0 is success.
     d. Iterate `whisper_full_n_segments(context)` and collect text via `whisper_full_get_segment_text(context, i)`, joining into a single String.
     e. Return the trimmed transcription string.

   - IMPORTANT: The `transcribe` method reads the WAV file bytes directly using `Data(contentsOf: audioURL)`, NOT using AVAudioFile or AVFoundation (simpler, no extra framework needed since we know the exact WAV format).

3. **Verify build**: `swift build` must succeed with the new whisper.spm dependency resolved and TranscriptionManager compiling.
  </action>

<task type="auto">
  <name>Task 2: Create ModelManager for on-demand model download</name>
  <files>aihelper/ModelManager.swift</files>
  <action>
1. **Create `aihelper/ModelManager.swift`** -- manages whisper model file lifecycle:

   - `final class ModelManager` (not actor -- only does file/download operations, no whisper context).
   - Static `shared` singleton instance.
   - `modelDirectoryURL` computed property: `FileManager.default.urls(for: .applicationSupportDirectory, in: .userDomainMask).first!.appendingPathComponent("aihelper/models")`. Create directory if it doesn't exist (with `createIntermediateDirectories: true`).
   - `modelPath` computed property: returns the full path string to `ggml-base.bin` inside the model directory.
   - `var isModelDownloaded: Bool` -- checks if the file at `modelPath` exists using FileManager.
   - `func downloadModel(progress: @escaping (Double) -> Void) async throws`:
     a. If model already exists, return immediately.
     b. Download from `https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-base.bin` using URLSession.
     c. Use `URLSession.shared.bytes(from: url)` for streaming download with progress reporting. The expected file size is ~148MB. Calculate progress from bytes received vs Content-Length header.
     d. Write to a temporary file first, then move to final `modelPath` atomically using `FileManager.default.moveItem`.
     e. If download fails, clean up the temp file.
   - Use `ggml-base.bin` (not tiny) because: base model has significantly better multi-language accuracy (TRX-03 requires German+English), and on Apple Silicon Macs with Metal acceleration the base model still transcribes under 3 seconds for 30s audio (TRX-02).
   - IMPORTANT: This is the ONLY network call in the entire app -- it happens once at first launch for model setup. All transcription is fully local after this.
